Featured Research

Undergraduate Thesis · 2026

Leakage-Aware and Imbalance-Sensitive Deep Learning Framework for 12-Class RBC Morphology Classification

Developed a leakage-aware deep learning framework for red blood cell (RBC) morphology classification using smear-level data partitioning to prevent data leakage.

Implemented ConvNeXt and Swin Transformer architectures and applied Grad-CAM for explainable AI. The framework was evaluated using Accuracy, Precision, Recall, Macro-F1, and Confusion Matrix.
